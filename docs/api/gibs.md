# GIBS basemaps

NASA Global Imagery Browse Services — no API key.

## Templates (EPSG:3857)

- MODIS Terra True Color: `.../MODIS_Terra_CorrectedReflectance_TrueColor/default/{date}/GoogleMapsCompatible_Level9/{z}/{y}/{x}.jpg`
- VIIRS SNPP True Color: `.../VIIRS_SNPP_CorrectedReflectance_TrueColor/default/{date}/GoogleMapsCompatible_Level9/{z}/{y}/{x}.jpg`

Default `{date}` = NISAR before/after dates of the case (from site config / timeline).
