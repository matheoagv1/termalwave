# monigote/

Deja aca el monigote / mascota generado para TermalWave.

## Pedido (cricri)

1. Mergea `master` en `work/cricri` si te falta el directorio `brand/`.
2. Copia el archivo del monigote a esta carpeta (PNG preferido; transparent OK).
3. Nombre sugerido: `monigote.png` (o `monigote-fuente.png` + variantes si hace falta).
4. Avisa en `comms/cricri/outbox/` y deja nota en `comms/carne/inbox/` para que Emir lo use en UI.

No subas el monigote a `web/src/` directo: la fuente de verdad es `brand/monigote/`.
